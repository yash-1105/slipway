## Rules

- Implement what the specification says. If you find something it does not
  cover, implement the smallest reasonable thing and list the decision at the
  end under "Assumptions".
- Every acceptance criterion must have code that could satisfy it.
- Include the commands needed to install, run and test the result.
- If part of the specification cannot be implemented as written, say which part
  and why, and implement everything else. Do not silently narrow the scope.

## Output

The files to write, each with its full path and complete contents, followed by
an "Assumptions" section and a "Not implemented" section. Leave both sections in
place even when they are empty, so a reader can tell you considered them.
